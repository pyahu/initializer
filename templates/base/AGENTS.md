# Working in this repository

[[description]]

Generated by the [Pyahu Initializer](https://initializer.pyahu.io/) on baseline [[baseline]]: Java [[javaFeature]] and
Spring Boot [[springBoot]]. `README.md` shows how to run, build and deploy it. This page is what to know before
changing it.

## Where things are

| Path | What |
| ---- | ---- |
| `src/main/openapi/api.yaml` | The REST contract. Change it first: the build generates the interfaces the controllers implement. |
[[layout]]
| `src/main/resources/application.yaml` | Every setting, with local defaults the Deployment overrides. |
[[#postgres]]
| `src/main/resources/db/changelog/` | The Liquibase changelog, applied by the migration Job. |
[[/postgres]]
| `src/test/java/` | The tests. A test tagged `integration` starts the application or a container. |
[[#nextjs]]
| `frontends/web/` | The Next.js frontend. It renders on its server and calls the service from there. |
[[/nextjs]]
| `deploy/` | Kustomize: a base, a `dev` and a `prod` overlay. |
| `config/pmd/ruleset.xml` | The complexity rules. |

`ping` is the sample capability. It shows the shape of one: add yours as a package beside it, then remove it.

## Rules the build enforces

A change that breaks one of these fails `./gradlew build`. Fix the code. Do not lower a limit, switch a check off
or leave code out of one to get to green.

- **The architecture is [[architectureTitle]].** `ArchitectureTest` keeps each layer to what it may use and the domain
  to the JDK and JSpecify. `ModulithTest` keeps one capability to the public API of another.
- **Nothing is nullable unless it says so.** Every package is `@NullMarked`; NullAway and Error Prone run at
  compile time.
- **The contract and the code agree.** Controllers implement the interfaces generated from `api.yaml`[[#nextjs]],
  and the frontend's `src/api/schema.d.ts` is generated from the same file[[/nextjs]].
- **Formatting is Spotless.** Run `./gradlew spotlessApply` before you finish.
- **A method stays simple enough to change.** PMD fails the build on a method too complex to follow, a class that
  does too much, an empty `catch` and unused private code.
- **The business rules are tested.** In the domain and application packages, tests cover at least 80% of the
  lines and 70% of the branches.
- **The tests notice a mistake.** PIT changes that code and at least 70% of the changes must make a fast test
  fail. A test that runs the code and asserts nothing does not count.
[[#postgres]]
- **The service does not own the schema.** The migration role and the runtime role are different, and
  `DatabaseRolesTest` checks what each may do.
[[/postgres]]

## When the build fails

Every build writes `build/reports/pyahu/quality.json`, also when a task fails. `firstFailure` names the gate, the
reason, the command that reproduces it and the guide step that explains the fix; each gate lists its findings
with file and line. Read it before the console output, fix the cause, run that command, then `./gradlew build`.
People read the same report in `quality.html`.

## Rules nothing enforces, so follow them

- **A business rule gets a fast test**, without Spring and without a container.
- **Every setting has a local default in `application.yaml`** and the Deployment overrides it.
[[#postgres]]
- **Never edit a changeset that already ran.** Add a new one that the release still running can live with.
[[/postgres]]
- **Name the guide and the step** in a short comment where a reader would ask why, as the generated code does.

## Commands

```sh
./gradlew test             # the fast tests
./gradlew integrationTest  # the tests tagged integration[[#postgres]]; they need Docker[[/postgres]]
./gradlew check            # both, plus Spotless, PMD, coverage and mutation testing
./gradlew build            # check, then the jar and the SBOM
./gradlew spotlessApply    # format
open build/reports/pyahu/quality.html   # the quality report of the last build
[[#nextjs]]

cd frontends/web
npm ci
npm run api                # regenerate src/api/schema.d.ts after a change to api.yaml
npm run api:check          # fail when schema.d.ts is out of date
npm run build
[[/nextjs]]
```

## Upgrading to a newer baseline

The [release notes]([[releaseNotes]]) list every step after baseline [[baseline]], oldest first. Run a step's
**Needed when** command from the repository root and apply the step only when it exits 0, then run its **Check**.
A step that changes a file listed below goes in its own pull request.

## Leave these to a person

`gradle/wrapper/`, `gradle/quality-report/`, `gradlew`, `renovate.json`, `config/pmd/`, `.github/`,
`CHECKLIST.md` and this file hold the rules a change is judged by. A change to one of them is its own pull request,
with its reason.
